# Dogfood lessons

Only record lessons that repeat across multiple projects.

## Repeated lessons

### Research must become a decision and a regression case

- Seen in: Instagram accuracy hardening; earlier starter-kit research capture work.
- Pattern: research helps only when it is converted into a project decision, a runtime/docs guardrail, and a concrete regression scenario.
- Recommended kit change: add a `research-to-decision-to-fixture` recipe and template.
- Status:
  - pending

### Evidence contracts beat ad-hoc fixes

- Seen in: Instagram accuracy hardening; starter-kit eval-feedback guidance.
- Pattern: repeated failures recur when agents patch symptoms instead of defining which evidence is confirmed, candidate, diagnostic, or unknown.
- Recommended kit change: add evidence-contract prompts to debugging and review templates.
- Status:
  - pending

### Subagents need role-specific output contracts

- Seen in: Instagram accuracy hardening; multi-role review sessions.
- Pattern: subagents are most useful when each has a different lens and must return prioritized findings with implementation implications.
- Recommended kit change: add a synthesis template with `finding -> risk -> implication -> fixture`.
- Status:
  - pending
