# Research material examples

This folder shows optional research-heavy project artifacts.

These examples are not copied into scaffolded projects by default. Use them only
when papers, blogs, official docs, issues, or repos materially affect decisions.

See `recipes/research-material-management.md`.

Included examples:

- `chrome-extension-network-response-capture.md` captures a dogfood research
  note on Chrome extension options for reading DevTools Network response bodies.
- `dom-virtual-scroll-collection-stability.md` captures a dogfood research note
  on dynamic DOM, lazy rendering, and virtual scroll collection reliability.
